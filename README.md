# AGY Limits Bar (macOS & Windows)

<p align="center">
  <b>Нативная утилита Menu Bar для macOS и системного трея Windows для отслеживания квот и лимитов Google Antigravity (AGY) и Claude Code в реальном времени.</b>
</p>

---

## Возможности

- **Индикатор и анимированные логотипы в строке меню:**
  - Официальные векторные логотипы **Claude** и **Google Gemini** в Menu Bar.
  - **Динамическая анимация состояний:**
    - *В работе:* имитация размышления и генерации (плавное вращение и дыхание логотипа).
    - *Завершил / ожидает ответа:* логотип подпрыгивает, уведомляя о необходимости ввода.
    - *В покое:* статичное компактное отображение остатка лимитов.
- **Поддержка Claude Code по умолчанию:** автоматический выбор Claude при старте, отслеживание 5-часовых сессий и недельных квот официальной подписки Claude.
- **Точечный учет лимитов:**
  - **AGY (Antigravity):** вывод исключительно лимитов Gemini Models (5-часовой спринт и недельный резерв).
  - **Claude Code:** 5-часовая сессия и общий недельный лимит подписки.
- **Переключение провайдеров:** удобные вкладки «Claude», «Antigravity» и «Все» в едином интерфейсе.
- **Умный обратный отсчет:** точный расчет времени до сброса квот (*«сброс через 45м»*, *«сброс через 1ч 20м»*).
- **Мульти-профильность:** автоматическое обнаружение профилей `claude` и профилей `agy` (`~/.agy-profile-*`).
- **Баланс кредитов и тариф:** быстрый просмотр оставшихся Model Credits и статуса подписки.
- **Быстрый доступ к CLI:** кнопки мгновенного запуска `claude` и `agy` в терминале.
- **Современный нативный дизайн:** стеклянный интерфейс в стиле macOS с поддержкой светлой и темной темы.

## Установка на macOS

### Способ 1: Через Homebrew (рекомендуется)

Установка в один клик через официальный тап:

```bash
brew install --cask dan9zpam/tap/agylimit
```

Или с добавлением репозитория:
```bash
brew tap dan9zpam/tap
brew install --cask agylimit
```

### Способ 2: Скачать готовый релиз

1. Перейдите в раздел [Releases](https://github.com/dan9zpam/AgyLimitsBar/releases/latest).
2. Скачайте архив **`AgyLimitsBar-v1.1.0.zip`**.
3. Распакуйте и перетащите `AGY Limits Bar.app` в папку **Программы** (`/Applications`).
4. Запустите приложение.

*(Для автозапуска при включении Mac: «Системные настройки» ➔ «Основные» ➔ «Объекты входа» ➔ добавьте AGY Limits Bar).*

### Способ 3: Сборка из исходников

```bash
git clone https://github.com/dan9zpam/AgyLimitsBar.git
cd AgyLimitsBar
./build_app.sh
open "AGY Limits Bar.app"
```

## Установка на Windows

Для Windows доступна портативная сборка для системного трея (около часов):

1. Скачайте `AgyLimitsWindows.zip` из папки `AgyLimitsWindows` или раздела [Releases](https://github.com/dan9zpam/AgyLimitsBar/releases).
2. Распакуйте архив и запустите `AgyLimitsWindows.exe`.
3. Приложение свернется в системный трей и будет отображать текущие лимиты активного профиля.

---

## Требования

* **macOS 13.0 (Ventura) или новее** / **Windows 10/11**
* Установленный и авторизованный CLI `agy` (Google Antigravity).
